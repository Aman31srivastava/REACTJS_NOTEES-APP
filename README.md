# REACTJS_NOTES-APP

# 📝 Smart Notes App

A modern **React-based Notes Application** that allows users to create, edit, search, pin, and delete notes with a clean UI and dark mode support.
The application also saves notes locally using **LocalStorage**, so your notes remain available even after refreshing the page.

Built with ❤️ by **Aman Srivastava**

---

## 🚀 Features

* ✍️ Add new notes
* 📝 Edit existing notes
* 🗑 Delete notes
* 📌 Pin important notes
* 🔍 Search notes instantly
* 🌙 Toggle Dark Mode
* 💾 Auto-save notes using LocalStorage
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* 🔗 Footer with social links

---

## 🛠 Tech Stack

* **React.js**
* **JavaScript (ES6+)**
* **CSS3**
* **React Icons**
* **LocalStorage API**

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/smart-notes-app.git
```

### 2️⃣ Navigate to the project folder

```bash
cd smart-notes-app
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Install icons

```bash
npm install react-icons
```

### 5️⃣ Start the development server

```bash
npm run dev
```

The application will run on:

```
http://localhost:5173
```
